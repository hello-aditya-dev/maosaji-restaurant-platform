# Maosaji Restaurant Platform — Zai Build Pack

Prepared: 2026-09-18 (Asia/Kolkata)

## Purpose
This pack is the durable source of truth for building a private, premium Maosaji website/platform concept for an in-person sales demonstration in Bilaspur.

The project is NOT a generic restaurant template and NOT a fake official Maosaji website. It is a private concept implementation of a reusable restaurant platform.

## Start here
1. `01_ZAI_MASTER_PROMPT.md` — paste this entire file into Zai.
2. `02_VERIFIED_FACTS.json` — facts Zai may treat as current/publicly verified as of 2026-09-18.
3. `03_CONTENT_AND_DATA_RULES.md` — prevents invented claims/data.
4. `04_SEED_DATA.json` — safe demo seed data.
5. `05_ACCEPTANCE_TESTS.md` — the definition of done.
6. `06_FINAL_AUDIT_PROMPT.md` — mandatory second-pass audit after Zai says the build is done.
7. `07_DEMO_RUNBOOK.md` — exactly how Aditya should demo the product.
8. `08_REBRAND_GUIDE.md` — makes the platform reusable for another restaurant.
9. `09_PRODUCTION_HANDOFF_CHECKLIST.md` — what changes only after Maosaji approves.
10. `SOURCE_CONTEXT_FULL.md` — full planning source supplied by the user.

## Core principle
Build one reusable Restaurant Platform and skin it for Maosaji. If Maosaji does not proceed, the same engine must be rebrandable for ORO, Lalaji, or another restaurant without rewriting the application.

## Demo safety
- The demo must be `noindex,nofollow`.
- It must visibly state that it is an unofficial private concept.
- It must never send real notifications to Maosaji.
- It must not claim to be the official Maosaji site.
- It must not fabricate heritage/history, ownership, reviews, prices, opening times, certifications, delivery capability, or testimonials.
